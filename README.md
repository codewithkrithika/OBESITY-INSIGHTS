# Obesity Insights – Data Analysis & Machine Learning

## Project Overview
This project analyses obesity levels based on demographic details, eating habits, physical activity and lifestyle factors using Python and Machine Learning.

## Dataset Details
- Records: 2,111
- Features: 17
- Target Variable: `NObeyesdad`
- Problem Type: Multiclass Classification

## Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Outlier Detection
6. Feature Selection
7. Data Preprocessing
8. Machine Learning Model Training
9. Model Evaluation

## Machine Learning Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)

## Expected Outcome
Analyse obesity-related patterns, identify important lifestyle factors and compare machine learning model performance.

## Conclusion
This project demonstrates the use of Python and Machine Learning for obesity data analysis and classification.

**Domain:** Data Analytics | Machine Learning | Python
